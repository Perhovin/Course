# Course Information Display

A simple console application written in C#. This is my educational project to practice and learn basic Object-Oriented Programming (OOP) concepts.

## Features

* **Course creation:** Defines a custom `Course` object to store educational data.
* **Data assignment:** Keeps track of the course name, number of credits, and the teacher's name.
* **Console output:** Formats and prints the assigned course details clearly to the terminal.

## What I learned in this project

* How to create and structure a basic `class` in C#.
* How to instantiate an `object` from a class using the `new` keyword.
* How to define and assign values to `public` fields.
* How to organize code by splitting it into multiple files (`Program.cs` and `Course.cs`).
* How to use string interpolation (`$""`) to output variables smoothly into text.
